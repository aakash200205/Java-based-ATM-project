# Teller Machine (ATM) - Java Project

This Teller Machine (ATM) is developed in **Java**. It offers users basic banking services such as:

- Checking balance
- Withdrawing funds
- Depositing funds

## Features

The project is implemented with robust security features to ensure safe and secure transactions, including:

- **Encryption techniques** for storing and processing sensitive data such as PINs and account details.
- Simulation of the functionality of an Automated Teller Machine (ATM).

## Overview

This project serves as a simulation program designed to replicate the functionality of an Automated Teller Machine (ATM). It provides a user-friendly interface for performing essential banking operations while prioritizing security and reliability.
